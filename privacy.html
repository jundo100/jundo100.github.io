プライバシーポリシー(kato-clips uploader)

最終更新: 2026年11月21日

1. このツールについて

kato-clips uploader は、YouTube チャンネル「純度100% 加藤純一」(@jundo100)の運営者が、 自分のパソコンから自分のチャンネルへ動画をアップロードするためだけに使うツールです。一般には公開しておらず、運営者以外の人は使いません。

2. 使う Google のデータ

YouTube Data API の「動画のアップロード」の権限(https://www.googleapis.com/auth/youtube.upload)だけを使います。 動画をアップロードし、タイトル・説明・サムネイルを設定するために使います。視聴者の情報・コメント・メールアドレスなど、ほかのデータは読みません。

3. 保存と共有

Google から受け取る認証のトークンは、運営者のパソコンの中にだけ保存し、外部のサーバーには送りません。 受け取った情報を第三者に提供・販売したり、広告に使ったりはしません。

kato-clips uploader による Google API から受け取った情報の利用と移転は、 Google API Services User Data Policy(Limited Use の要件を含む)に従います。

4. 取り消し

Google アカウントの「サードパーティ製のアプリとサービス」(https://myaccount.google.com/connections)から、いつでもアクセスを取り消せます。

5. 問い合わせ

YouTube チャンネルの動画のコメント欄からお知らせください。

English summary

kato-clips uploader is a personal tool used only by the operator of the YouTube channel "純度100% 加藤純一" (@jundo100) to upload videos to that channel. It requests only the youtube.upload scope, stores the OAuth token only on the operator's own computer, and does not share, sell, or use Google user data for any other purpose. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/connections.
